#  📚 Source of Information – HRC Technologies

## 🏛️ US Lotto Results & Guide
Lottery results displayed in this app are sourced from third-party APIs, public data sources, and official lottery websites.

Powerball latest results are sourced from DrawAnalytics API – https://www.drawanalytics.com/api/v1/$slug/powerball/latest

New York lottery data is sourced from New York State Open Data – https://data.ny.gov/resource/d6yy-54nr.json

The Multi-State Lottery Association (MUSL) is also used as a reference source for information related to participating multi-state lottery games – https://www.musl.com/

## 💱 Currency Converter & Tools
The exchange rate data used in this app is sourced from CurrencyFreaks, a trusted provider of real-time currency exchange rates.
All conversion values displayed are based on the most recent data available from their API.

For more details, visit: https://currencyfreaks.com
